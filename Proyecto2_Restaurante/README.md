# Sistema de Gestión de Restaurante

### Descripción del Proyecto

El proyecto consiste en un sistema de gestión de restaurante que permite a los usuarios administrar de manera eficiente las operaciones diarias del establecimiento. Este sistema está diseñado para mejorar la experiencia del cliente y optimizar la gestión interna del restaurante, incluyendo funcionalidades como la gestión de reservas, pedidos, inventario y facturación.

### Funcionalidades Principales
* Registrar clientes: Los usuarios pueden agregar, editar y eliminar clientes en su base de datos.
* registrar numero de personas: Los usuarios pueden registrar el número de personas que asistirán a una reserva o evento en el restaurante.
* agregar a la lista de espera: Los usuarios pueden agregar clientes a una lista de espera en caso de que no haya mesas disponibles.
* asignar mesa: Los usuarios pueden asignar mesas a los clientes según la disponibilidad y el tamaño del grupo.
* cancelar reserva: Los usuarios pueden cancelar reservas existentes y notificar a los clientes afectados.
* buscar cliente: Los usuarios pueden buscar clientes específicos en la base de datos para gestionar reservas y pedidos de manera más eficiente.
* eliminar cliente: Los usuarios pueden eliminar clientes de la base de datos según sea necesario.
* Mostrar lista de espera: Los usuarios pueden visualizar la lista de espera actual para gestionar mejor la asignación de mesas.
* mostrar mesas disponibles: Los usuarios pueden ver las mesas disponibles en tiempo real para asignarlas a los clientes de manera eficiente.
