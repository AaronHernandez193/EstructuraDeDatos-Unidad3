# Sistema de Simulación de Llamadas Telefónicas

### Descripción del Proyecto
El proyecto consiste en un sistema de simulación de llamadas telefónicas que permite a los usuarios realizar y recibir llamadas virtuales. Este sistema está diseñado para proporcionar una experiencia realista de comunicación telefónica, incluyendo funcionalidades como la marcación de números, la recepción de llamadas entrantes y la gestión de contactos.

### Funcionalidades Principales
* Registro de contactos: Los usuarios pueden agregar, editar y eliminar contactos en su lista de contactos.
* Atender llamadas: Los usuarios pueden recibir llamadas entrantes y decidir si desean contestarlas o rechazarlas.
* Finalización de llamadas: Los usuarios pueden finalizar una llamada en curso en cualquier momento.
* Historial de llamadas: El sistema mantiene un registro de todas las llamadas realizadas y recibidas, incluyendo la duración y la hora de cada llamada.
* recuperar ultima llamada: Los usuarios pueden acceder rápidamente a la información de la última llamada realizada o recibida.
* buscar contacto: Los usuarios pueden buscar contactos específicos en su lista de contactos para realizar llamadas de manera más eficiente.
* eliminar contacto: Los usuarios pueden eliminar contactos de su lista según sea necesario.
